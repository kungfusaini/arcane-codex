Shortlist deck

Simple, customizable Notion-like tools

A quick visual comparison of AppFlowy, AFFiNE, Docmost, SiYuan, Trilium, and BlockNote — focused on whether they are good starting points for an open-source Notion-style product.

How to judge them

Notion is not one feature. It is a workspace model.

Editor feel

Blocks, slash commands, drag/drop, embeds, markdown shortcuts, and whether writing feels fast.

Structure

Nested pages, backlinks, tables/databases, kanban, calendar, templates, and permissions.

Customizable base

Open-source license, self-hosting, plugin model, theming, and how hard it is to fork or extend.

AppFlowy

Closest Notion clone
  • Best all-round starting point if you want pages, tasks, tables, boards, and collaboration.
  • Feels intentionally Notion-like without being only a wiki.
  • Good candidate to use or study before building from scratch.

AFFiNE

Docs + whiteboard
  • Most visually ambitious: combines Notion-style docs with Miro-style canvas thinking.
  • Strong if the product should support planning, diagrams, and visual knowledge work.
  • License and source model should be reviewed carefully before depending on it.

Docmost

Team wiki
  • Cleanest fit for collaborative documentation and internal knowledge bases.
  • Includes pages, real-time editing, spaces, comments, diagrams, and permissions.
  • Less of a full Notion database workspace; more Confluence/Notion docs.
Power-user notes

SiYuan and Trilium are strong for personal knowledge management.

SiYuan

Local-first PKM

Block references, backlinks, markdown, privacy-first. Better for individual knowledge systems than team workspaces.

Trilium

Scriptable notes

Extremely powerful and customizable, but the UI feels more technical and less consumer-polished.

Takeaway

Both are useful references for linking, hierarchy, local-first storage, and extensibility — not the strongest visual model for a new Notion-like app.

BlockNote

Build-your-own layer
  • Not a full app. It is a React block editor library.
  • Good if the real goal is to build a simple custom open-source Notion.
  • You still need workspace, auth, storage, search, databases, sharing, and sync.
